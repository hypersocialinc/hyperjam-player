HyperJam Player

A web component that plays Strudel code. Press play on any of these.

A track from HyperJam

<hyperjam-player track="tidal-arpeggio"> loads the track, its cover and its code.

Your own code

Inline Strudel in a <script type="text/strudel">. No cover, so it gets a plain sleeve in its colour.

Live swap

Buttons call player.setCode(code). While it plays, the new code crossfades in on its own beat 1. This is what the live API will call.
